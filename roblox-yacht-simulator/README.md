# Roblox ヨットレースシミュレーター

「子供は5分で楽しめて、大人は何年でも極められる本格ヨットシミュレーター」

## セットアップ

1. [Rojo](https://rojo.space/) をインストール
2. `rojo serve` でRoblox Studioと同期
3. Roblox StudioでRojoプラグインから接続

## プロジェクト構成

```
src/
  server/    -- サーバースクリプト（風・レース管理）
  client/    -- クライアントスクリプト（操作・UI）
  shared/    -- 共有モジュール（物理演算・設定）
  gui/       -- UI画面
  storage/   -- サーバーストレージ
  workspace/ -- ワークスペース設定
```

## 操作モード

- **キッズモード**: 舵のみ操作、セイル自動、転覆しにくい
- **ノーマルモード**: 舵＋メインセイル、タッキング・ジャイビング
- **プロモード**: フルセイルコントロール、ヒール管理、本格レース
